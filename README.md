# 🎨 RGB Color Detection with OpenCV & Python

> Implementasi pemrosesan citra digital untuk mendeteksi, mengisolasi, dan menganalisis komponen warna RGB/HSV secara *real-time* menggunakan kamera atau berkas gambar.

---

## ⚡ Fitur Utama

- 🔍 **Real-time Color Tracking:** Tracking warna tertentu berdasarkan ambang batas (*thresholding*) HSV/RGB.
- 📐 **Adaptive Thresholding & Masking:** Pengolahan citra dengan reduksi *noise* dan operasi morfologi.
- 🖱️ **Interactive Pixel Inspection:** Menampilkan nilai warna piksel secara presisi saat kursor diarahkan ke gambar.

---

## 🛠️ Tech Stack & Prasyarat

- **Python 3.x**
- **OpenCV (`opencv-python`)**
- **NumPy & Matplotlib**

---

```bash
git clone [https://github.com/ichwanfauzi/rgb-color-detection-opencv.git](https://github.com/ichwanfauzi/rgb-color-detection-opencv.git)
cd rgb-color-detection-opencv
pip install opencv-python numpy matplotlib
